
目標：
打造一個 workflow 解決下面的問題

預先設定：
用戶訪問前端畫面的時候，後台會主動分配：
- `user_id`: 用戶的代號
- `thread_id`: 本次對話的代號
- `user_workspace`: 用戶在這個 workflow 中的工作空間

情境：
用戶上傳一張表格資料，格式為 CSV 檔案，
該檔案會被後台程序整理在在 DuckDB 資料庫。
接著用戶可以用自然語言跟代理互動，回答以下問題完成任務：

1. 我想用 ANOVA 分析 A 欄位與 B 欄位，給我分析報告
2. 我想用 ANOVA 分析 A 欄位與結尾包含 _C 的欄位，給我分析報告
3. 我想用 ANOVA 分析 A 欄位與結尾包含 _C 的欄位，將差異最多的前面 3 筆整理並給我分析報告
4. 我想用 ANOVA 分析 A 欄位與結尾包含 _C 的欄位，將差異最多的前面 3 筆資料畫出箱型圖，並且整理一份分析報告
